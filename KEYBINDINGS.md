# Keybindings

## General

| Key | Action |
|-----|--------|
| `<C-s>` | Save |
| `qq` | Quit |
| `qa` | Quit all |
| `qw` | Save & quit |
| `q!` | Force quit |
| `<Esc>` | Clear search |
| `<leader>e` | Toggle NvimTree |
| `<S-h>/<S-l>` | Prev/next buffer |
| `<leader>u` | Toggle Undotree |

## Navigation

| Key | Action |
|-----|--------|
| `<C-h/j/k/l>` | Navigate windows |
| `<C-d/u>` | Scroll down/up (centered) |
| `<A-Up/Down/Left/Right>` | Resize splits |

## Telescope (Fuzzy Finder)

| Key | Action |
|-----|--------|
| `<leader>ff` | Find files |
| `<leader>fg` | Live grep |
| `<leader>fb` | Buffers |
| `<leader>fs` | Workspace symbols |
| `<leader>fd` | Document symbols |
| `<leader>ft` | Find test files |

## LSP

| Key | Action |
|-----|--------|
| `gd` | Go to definition |
| `K` | Hover |
| `gr` | References |
| `<leader>rn` | Rename |
| `<leader>ca` | Code actions |
| `<leader>gf` | Format buffer |
| `gq` | Format current line |

## Git

| Key | Action |
|-----|--------|
| `<leader>gg` | Toggle LazyGit |
| `]c` / `[c` | Next/prev hunk |
| `<leader>gs` | Stage hunk |
| `<leader>gr` | Reset hunk |
| `<leader>gc` | Neogit |

## Terminal

| Key | Action |
|-----|--------|
| `<leader>tt` | Toggle terminal |
| `<C-\>` | Toggle terminal |

## Python (REPL)

| Key | Action |
|-----|--------|
| `<leader>rr` | Open Python REPL |
| `<leader>rc` | Send to REPL |

## Python (Pytest)

| Key | Action |
|-----|--------|
| `<leader>pt` | Run all tests |
| `<leader>pc` | Run tests (verbose) |
| `<leader>pd` | Run tests (debug, stop on first failure) |

## Jupyter

| Key | Action |
|-----|--------|
| `<leader>jc` | Jupyter: Send cell/selection |
| `<leader>jr` | Jupyter: Run current line |
| `<leader>jk` | Jupyter: Restart kernel |

## Virtual Environment

| Key | Action |
|-----|--------|
| `<leader>vp` | Pick virtualenv |
| `<leader>vs` | Show venv status |

## Text

| Key | Action |
|-----|--------|
| `gc` | Comment line |
| `gcc` | Toggle comment |
| `s` | Flash jump |

## Harpoon

| Key | Action |
|-----|--------|
| `<leader>ha` | Add file to Harpoon |
| `<leader>hh` | Toggle Harpoon menu |
| `<leader>h1-h4` | Navigate to file 1-4 |

## File Explorer

| Key | Action |
|-----|--------|
| `-` | Open parent directory (Oil) |

## Todo Comments

| Key | Action |
|-----|--------|
| `]t` / `[t` | Next/prev todo comment |

## Tabs

| Key | Action |
|-----|--------|
| `tn` | New tab |
| `to` | Only this tab |
| `tc` | Close tab |
| `tm` | Move tab |
