# Keybindings

## General

| Key | Action |
|-----|--------|
| `<C-s>` | Save |
| `qq` | Quit |
| `<Esc>` | Clear search |
| `<leader>e` | Toggle NvimTree |
| `<S-h>/<S-l>` | Prev/next buffer |

## Telescope (Fuzzy Finder)

| Key | Action |
|-----|--------|
| `<leader>ff` | Find files |
| `<leader>fg` | Live grep |
| `<leader>fb` | Buffers |
| `<leader>fs` | Workspace symbols |
| `<leader>fd` | Document symbols |
| `<leader>ft` | Find test files |

## LSP

| Key | Action |
|-----|--------|
| `gd` | Go to definition |
| `K` | Hover |
| `gr` | References |
| `<leader>rn` | Rename |
| `<leader>ca` | Code actions |
| `<leader>gf` | Format buffer |

## Git

| Key | Action |
|-----|--------|
| `<leader>tg` | Toggle LazyGit |
| `]c` / `[c` | Next/prev hunk |
| `<leader>gs` | Stage hunk |
| `<leader>gr` | Reset hunk |

## Terminal

| Key | Action |
|-----|--------|
| `<C-\>` | Toggle terminal |
| `<leader>tt` | Toggle terminal |

## Python

| Key | Action |
|-----|--------|
| `<leader>rr` | Open Python REPL |
| `<leader>rc` | Send to REPL |
| `<leader>pt` | Run all tests |
| `<leader>pc` | Run tests (verbose) |
| `<leader>pd` | Run tests (debug) |
| `<leader>jc` | Jupyter: Send cell |
| `<leader>jr` | Jupyter: Run line |
| `<leader>jk` | Jupyter: Restart kernel |
| `<leader>vp` | Pick virtualenv |
| `<leader>vs` | Show venv status |

## Text

| Key | Action |
|-----|--------|
| `gc` | Comment line |
| `gcc` | Toggle comment |
| `s` | Flash jump |

## Window

| Key | Action |
|-----|--------|
| `<C-h/j/k/l>` | Navigate |
| `<C-d/u>` | Scroll down/up |
